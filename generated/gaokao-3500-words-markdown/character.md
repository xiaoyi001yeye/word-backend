35.  character   n.（汉）字,  性质;  品格【英语单词 character 来自希腊语 kharakter ，本意是“刻下的印记”， 来自 kharax （尖头的棍子）。由此产生了 character 的基本含义“符号、印记”。古代希腊人认为，环境和人的成长经历会在人的身心留下印记，从 而使其具有与众不同的性格特征，因此 character 又衍生出“性格、个性、特征”的含义。在文学、戏剧等艺术作品中，作者通过对人物性格的刻画，从而 塑造出个性鲜明的人物，这种“人物角色”也被称
为 character 。】
